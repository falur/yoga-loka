# YogaLoka

YogaLoka — серверная часть социальной сети для людей, которые практикуют йогу. Проект работает на PHP 8.5, Spiral Framework, Cycle ORM, PostgreSQL и RoadRunner.

## Стадия проекта

Проект находится в стадии разработки: продакшена ещё нет, пользователей и рабочих данных нет.

Что из этого следует:

- Базу данных, очереди RabbitMQ, Redis и MinIO можно пересоздавать с нуля; совместимость с уже применёнными миграциями, накопленными записями outbox и сообщениями в очереди обеспечивать не нужно.
- Обратная совместимость публичного HTTP API не требуется: внешних потребителей нет.
- Изменение формата интеграционных событий и значений их типов безопасно, пока очередь и outbox пересобираются.
- Решения принимай в пользу правильной формы, а не в пользу совместимости со старым состоянием.

Когда появится продакшен, убери этот раздел и пересогласуй правила миграций и совместимости.

## Обязательные документы

До анализа или изменения проекта прочитай и соблюдай:

- `docs/rules.md` — проверяемые правила работы и кода;
- `docs/arch.md` — текущее состояние и целевая архитектура;
- `docs/references.md` — индекс эталонов кода, применимых к задаче;
- `docs/business.md` — индекс бизнес-карточек; читай только карточки, относящиеся к текущей задаче.

Бизнес-карточки описывают целевое поведение продукта. Не меняй их без `eda-business`.

Отвечай по-русски и простыми словами. Не используй Markdown-таблицы в ответах пользователю; при необходимости рисуй таблицу в блоке `text`. Не выдавай предположение за факт; значимую неясность или компромисс сообщи до реализации.
