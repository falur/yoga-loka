## Решения по optional

- **Принято:**
  - **Сверка 1** — дешёвая документ-правка, снимает реальный риск: ревьюер, доверяя плану («перебить `OpenApiGenerator` в контейнере»), искал бы fake-генератор, которого по техническим причинам быть не может. В план (фаза 6, пункт `OpenApiGenerateCommand`) добавлен явный механизм: `OpenApiGenerator` — `final readonly class`, бинд fake невозможен; error-ветка (`catch (OpenApiException ...)`) покрывается через несуществующий `openapi.sourcePath` → реальный генератор бросает `OpenApiException` из guard `OpenApiGeneratorConfig::validate()` (`is_dir` → `OpenApiConfigurationException extends OpenApiException`). Зафиксировано, что возврат к подмене генератора невозможен и что при удалении guard'а в пакете error-ветка перестанет покрываться (всплывёт на гейте 100%). Код продакшна не трогался.
  - **Сверка 2** — выполнено как обязательный финальный прогон скилла: `make qa` (cs + phpstan + test-coverage) даёт `Покрытие 100.00%` и exit 0. Подтверждено, что локальное дерево не разошлось с зафиксированным состоянием.
  - **Замечание 1** — дёшево и без риска регрессии: внутризадачная противоречивость (продакшн объявил тот же guard мёртвым и убрал, а тест его оставил) снята. Guard `if (!$fileInfo instanceof \SplFileInfo) { continue; }` в `removeRecursively()` заменён аннотацией `/** @var \SplFileInfo $fileInfo */` по образцу продакшн-команды `OpenApiPublishAssetsCommand::copyDirectory()`. `RecursiveDirectoryIterator` с дефолтными флагами всегда отдаёт `SplFileInfo` (режим `CHILD_FIRST` влияет только на порядок обхода), поведение теста не меняется. PHPStan level max зелёный.
  - **Замечание 3** — устраняет формальное нарушение `rules.md` «Без явного `mixed`» при нулевом риске (изолировано в тест-фикстурах):
    - `LazyGhostMapperDefensiveTest`: универсальный хелпер `invoke(): mixed` с `@param list<mixed> $args` удалён — каждый тест зовёт `ReflectionMethod` напрямую (значение результата потребляет `assertSame`/`expectException`, без `mixed`-сигнатур). Замыкания `schemaReturning` сужены с `: mixed` до конкретных `int` / `string|null` / `int|string|null`; для children добавлен типизированный хелпер `schemaReturningChildren(array<string, string>)` с замыканием `: array|null`. Параметр `setProperty(mixed $value)` сужен до `string|object|array<string, string>` (PHPDoc-генерик задан).
    - `ValueObjectCastDefensiveTest`: `StubValueObject` — `mixed $stored` и `value(): mixed` сужены до `object|null` (покрывает все три фактических входа: `null`, `DateTimeImmutable`, `stdClass`).

- **Отклонено:**
  - **Замечание 2** (рефлексия приватного API Spiral/Cycle — `AbstractKernel::$finalizer`, `ExceptionHandler::$reporters`, `RelationMap::$innerRelations`, приватные свойства `LazyGhostMapper`) — само ревью даёт рекомендацию «оставить как есть (план санкционировал, пометки добавлены), дополнять не требуется». Пометки «чинить при апгрейде» проставлены в прошлом круге. Это фиксация известного техдолга хрупкости, а не дефект; правка не нужна. Следующим ревьюерам: переоткрывать только при появлении публичного пути к тем же недостижимым веткам без рефлексии приватного API фреймворка.
