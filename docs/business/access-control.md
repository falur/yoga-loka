# Роли и права доступа

## Назначение и границы

Карточка описывает доступ к служебным и чувствительным действиям YogaLoka.

Обычные пользовательские возможности определяются правилами соответствующих разделов продукта. Роли используются для административных действий, модерации и управления доступом.

## Участники и термины

- Право — разрешение выполнить конкретное служебное действие.
- Роль — именованный набор прав.
- Управляющий доступом — пользователь, которому разрешено создавать роли, менять их и назначать пользователям.
- Защищённая роль — основная роль управления доступом, которую нельзя удалить или оставить без владельца.

## Права доступа

- YogaLoka содержит определённый набор поддерживаемых прав.
- Произвольные права создавать нельзя. Каждому праву должно соответствовать реальное действие продукта.
- При появлении нового служебного действия в систему добавляется новое право.
- При выполнении действия система проверяет конкретное право, а не название роли.
- Если необходимого права нет, действие запрещается.

Отдельные права могут разрешать:

- рассматривать жалобы;
- блокировать разные виды содержимого;
- предупреждать пользователей;
- блокировать пользователей;
- снимать блокировки;
- подтверждать профили;
- снимать подтверждение профилей;
- управлять справочником направлений и рассматривать предложения пользователей;
- смотреть статистику модераторов;
- смотреть историю решений;
- пересматривать решения;
- отменять решения;
- создавать и изменять роли;
- назначать и снимать роли;
- смотреть историю изменений доступа.

## Роли

- Роль объединяет одно или несколько прав.
- Название роли само по себе не предоставляет доступ.
- Можно создавать собственные роли из доступных прав.
- Одному пользователю можно назначить несколько ролей.
- Права пользователя складываются из всех его ролей.
- Роли не наследуются друг от друга.
- Запрещающие права не используются.
- Отдельные права напрямую пользователю не назначаются.
- Если пользователю нужен особый набор прав, создаётся подходящая роль.
- Изменение прав роли сразу применяется ко всем пользователям с этой ролью.
- Обычную роль можно изменить или удалить при наличии соответствующего права.
- Защищённую роль управления доступом удалить нельзя.

Названия «Модератор», «Проверяющий модераторов» или «Старший модератор» являются только названиями наборов прав. Доступ всегда определяется правами внутри роли.

## Назначение ролей

- Роль просто назначается выбранному пользователю.
- Никакая причина при назначении не требуется.
- Срок действия не указывается.
- Роль действует, пока её не снимут.
- Повторное назначение той же роли не создаёт дубликат.
- После назначения пользователь сразу получает права роли.
- После снятия роли предоставленные ею права сразу прекращают действовать.
- Снятие одной роли не затрагивает права, полученные через другие роли.

## Управление доступом

Управление доступом разделяется на отдельные права:

- просмотр ролей и их прав;
- создание, изменение и удаление ролей;
- назначение и снятие ролей;
- просмотр истории изменений доступа;
- управление защищённой ролью.

Это позволяет, например, разрешить человеку назначать готовые роли, но не разрешать менять их состав.

В системе всегда должен оставаться хотя бы один пользователь с защищённой ролью управления доступом.

Нельзя:

- удалить защищённую роль;
- снять защищённую роль с последнего её владельца;
- изменить доступ так, чтобы никто больше не мог управлять ролями.

## История изменений

Изменения доступа сохраняются автоматически. Пользователю не нужно вводить причину или дополнительные сведения.

Для каждого изменения сохраняются:

- кто выполнил действие;
- над каким пользователем или ролью;
- что именно изменилось;
- когда произошло изменение.

В истории учитываются:

- создание, изменение и удаление роли;
- добавление и удаление права из роли;
- назначение и снятие роли у пользователя.

История не изменяется и не удаляется. Она сохраняется после удаления роли или снятия роли с пользователя.

## Применение к модерации

Для контроля модераторов не требуется жёсткая должность или иерархия.

Любому пользователю можно назначить роль с необходимыми правами:

- рассматривать жалобы;
- применять определённые меры;
- смотреть статистику других модераторов;
- смотреть их решения;
- пересматривать решения;
- отменять решения.

Просмотр работы модераторов и изменение их решений являются разными правами.

Каждое действие модератора сохраняется за конкретным пользователем. История остаётся доступной, даже если позднее его роли изменили или сняли.

## Основные сценарии

### Создание роли

1. Пользователь с необходимым правом задаёт название роли.
2. Выбирает права из доступного каталога.
3. YogaLoka создаёт роль.
4. Действие автоматически сохраняется в истории.

### Назначение роли

1. Пользователь с необходимым правом выбирает человека и роль.
2. YogaLoka назначает роль.
3. Человек сразу получает права этой роли.
4. Назначение автоматически сохраняется в истории.

### Изменение роли

1. Пользователь с необходимым правом добавляет или удаляет права.
2. Изменение сразу применяется ко всем владельцам роли.
3. Действие автоматически сохраняется в истории.

### Снятие роли

1. Пользователь с необходимым правом снимает роль с человека.
2. Права этой роли сразу прекращают действовать.
3. Права из других ролей сохраняются.
4. Действие автоматически сохраняется в истории.

## Состояния и исключения

- Роль либо назначена пользователю, либо не назначена.
- Удалённое из роли право сразу перестаёт действовать у всех владельцев роли.
- Если такое же право доступно через другую роль, пользователь его сохраняет.
- Попытка выполнить действие без нужного права отклоняется.
- Повторное назначение уже назначенной роли не создаёт вторую связь.
- Последнего владельца защищённой роли удалить нельзя.

## Критерии готовности

- Служебное действие разрешается только при наличии соответствующего права.
- Пользователю можно назначить несколько ролей.
- Итоговый доступ складывается из всех назначенных ролей.
- Права напрямую пользователю не выдаются.
- Можно создавать роли с разными наборами поддерживаемых прав.
- Роль назначается без причины и срока действия.
- Изменение роли сразу влияет на всех её владельцев.
- Снятие роли сразу прекращает полученный через неё доступ.
- Все изменения автоматически сохраняются в неизменяемой истории.
- Нельзя удалить последнего владельца защищённой роли.
- Просмотр решений модератора не даёт права изменять или отменять эти решения.
