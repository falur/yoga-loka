# Вход и регистрация

## Назначение и границы

Карточка описывает вход без пароля, регистрацию нового пользователя, продление входа, выход и управление сессиями. Редактирование профиля и права пользователей в эту тему не входят.

## Участники и термины

- Посетитель — человек, который ещё не вошёл в YogaLoka.
- Пользователь — человек с зарегистрированным аккаунтом.
- Код входа — одноразовый шестизначный код из письма.
- Разрешение на регистрацию — одноразовое подтверждение того, что новый пользователь проверил адрес электронной почты и может завершить регистрацию.
- Сессия — отдельный вход пользователя на устройстве.
- Зарезервированный псевдоним — псевдоним, который нельзя получить при обычной регистрации.
- Защищённая ссылка — созданная администратором одноразовая ссылка, которая разрешает регистрацию нового пользователя с конкретным зарезервированным псевдонимом только для конкретного адреса электронной почты.

## Требования и правила

### Вход по коду

- Вход выполняется без пароля, по коду из письма.
- Код состоит из шести цифр и действует 10 минут.
- Запрос кода всегда даёт одинаковый ответ, чтобы нельзя было узнать, зарегистрирован ли адрес электронной почты.
- Повторный запрос в течение минуты не создаёт новый код и не отправляет новое письмо.
- После минуты новый код заменяет предыдущий.
- Код можно использовать только один раз.
- После пяти неверных попыток код больше нельзя использовать.
- Для неверного, использованного, отсутствующего или просроченного кода пользователь получает одинаковую ошибку.

### Существующий пользователь

- Активный пользователь после проверки кода сразу входит.
- Заблокированный, удалённый или неактивный пользователь войти не может.
- После успешного входа создаётся новая сессия.

### Новый пользователь

- После проверки кода новый пользователь получает разрешение на завершение регистрации.
- Разрешение действует 15 минут и используется один раз.
- Для регистрации обязательны имя, уникальный псевдоним и аватар.
- Имя содержит только буквы, пробелы, дефис и апостроф. Максимальная длина имени — 30 символов.
- Псевдоним содержит от 3 до 10 латинских букв, цифр, точек, дефисов или знаков подчёркивания.
- Псевдоним начинается и заканчивается буквой или цифрой и не содержит двух точек подряд.
- Аватаром может быть только успешно загруженное пользователем изображение.
- Занятый или зарезервированный псевдоним нельзя получить при обычной регистрации.
- Ошибка в имени, псевдониме или аватаре не сжигает разрешение на регистрацию: данные можно исправить и отправить повторно.
- После регистрации пользователь становится активным и автоматически входит.

### Зарезервированные псевдонимы

- Зарезервированный псевдоним недоступен в обычной регистрации, даже если его ещё не назначили другому пользователю.
- Получить зарезервированный псевдоним можно только по защищённой ссылке.
- Защищённую ссылку может создать только администратор.
- Защищённая ссылка привязана одновременно к одному псевдониму и одному адресу электронной почты.
- Защищённая ссылка действует 24 часа.
- Защищённая ссылка предназначена только для регистрации нового пользователя и не меняет псевдоним существующего пользователя.
- Ссылку нельзя использовать с другим адресом электронной почты или для другого псевдонима.
- Ссылку можно использовать только один раз.
- После успешной регистрации зарезервированный псевдоним назначается созданному пользователю, а ссылка перестаёт действовать.

### Сессии

- Короткий ключ доступа действует один час.
- Ключ продления входа действует 60 дней.
- Пользователь может иметь несколько сессий на разных устройствах.
- Для сессии сохраняются время создания, срок действия, сетевой адрес и сведения об устройстве, если они доступны.
- Продление входа заменяет оба ключа. Старые ключи больше не действуют.
- При выходе закрывается только текущая сессия.
- Пользователь может посмотреть свои действующие сессии и закрыть любую из них, включая текущую.
- Чужая или несуществующая сессия не раскрывается и считается ненайденной.

### Ограничение частоты

- Запросить код можно до пяти раз в минуту с одного сетевого адреса.
- Проверить код и завершить регистрацию можно до десяти раз в минуту с одного сетевого адреса.
- Продлить вход можно до двадцати раз в минуту с одного сетевого адреса.

## Сценарии и алгоритмы

### Вход существующего пользователя

1. Посетитель указывает адрес электронной почты.
2. YogaLoka отправляет код входа.
3. Посетитель вводит адрес электронной почты и полученный код.
4. Если аккаунт существует и активен, YogaLoka создаёт сессию и выполняет вход.

### Обычная регистрация

1. Посетитель запрашивает и проверяет код для ещё не зарегистрированного адреса электронной почты.
2. YogaLoka выдаёт разрешение на регистрацию.
3. Посетитель указывает имя и свободный незарезервированный псевдоним.
4. Посетитель загружает аватар.
5. YogaLoka создаёт активного пользователя и выполняет вход.

### Регистрация с зарезервированным псевдонимом

1. Администратор создаёт защищённую ссылку для адреса электронной почты и конкретного зарезервированного псевдонима.
2. Посетитель открывает защищённую ссылку в течение 24 часов после её создания.
3. YogaLoka проверяет, что ссылка не просрочена, ещё не использована и соответствует адресу электронной почты и псевдониму.
4. Посетитель указывает обязательные данные и загружает аватар.
5. YogaLoka создаёт активного пользователя, назначает ему зарезервированный псевдоним, гасит ссылку и выполняет вход.

### Продление входа

1. Пользователь передаёт действующий ключ продления.
2. YogaLoka закрывает прежнюю сессию и выдаёт новую пару ключей.
3. Повторное использование старого ключа отклоняется.

### Управление сессиями

1. Пользователь получает список своих действующих сессий и видит текущую сессию.
2. Пользователь выбирает сессию для закрытия.
3. YogaLoka закрывает выбранную сессию и делает её ключи недействительными.

## Состояния и исключения

- Код входа бывает действующим, использованным, просроченным или исчерпавшим число попыток.
- Разрешение на регистрацию бывает действующим, использованным или просроченным.
- Защищённая ссылка бывает действующей, использованной или просроченной. Ссылка, не соответствующая адресу электронной почты или псевдониму, отклоняется.
- Только активный пользователь может войти.
- Недействительный или просроченный ключ продления не продлевает вход.
- Закрытая сессия больше не даёт доступ к YogaLoka.

## Критерии приёмки

- Существующий активный пользователь входит по одноразовому коду без пароля.
- Новый пользователь после проверки кода может завершить регистрацию и сразу войти.
- Завершить обычную регистрацию или регистрацию по защищённой ссылке без аватара нельзя.
- Обычная регистрация не позволяет получить занятый или зарезервированный псевдоним.
- Зарезервированный псевдоним можно получить только при регистрации нового пользователя по созданной администратором одноразовой защищённой ссылке, которая действует 24 часа и связана с тем же псевдонимом и адресом электронной почты.
- Неверный код увеличивает число неудачных попыток, а после пятой попытки код больше не принимается.
- Продление входа делает прежние ключи недействительными.
- Выход и ручное закрытие сессии немедленно прекращают доступ через неё.
- Пользователь видит и закрывает только свои сессии.

## Расхождения с реализацией

Список зарезервированных псевдонимов уже хранится в `app/src/Modules/User/Domain/Entity/ReservedNickname.php:19`, а обычная регистрация уже отклоняет такие псевдонимы в `app/src/Modules/User/Application/Command/CreateUser/CreateUserHandler.php:42`.

Не реализованы создание администратором защищённых ссылок и регистрация нового пользователя с зарезервированным псевдонимом по одноразовой ссылке, которая действует 24 часа и привязана к конкретным псевдониму и адресу электронной почты.

Текущая регистрация не требует аватара, допускает имя длиной до 100 символов и псевдоним длиной до 30 символов. По целевым правилам аватар обязателен, имя ограничено 30 символами, а псевдоним — 10 символами.
