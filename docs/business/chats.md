# Чаты

## Назначение

Чаты позволяют двум пользователям обмениваться личными сообщениями в реальном времени.

В первой версии поддерживаются только личные диалоги.

## Участники

- Отправитель сообщения.
- Получатель сообщения.
- Система YogaLoka.

## Личный диалог

- Диалог состоит только из двух пользователей.
- Групповые диалоги в первой версии не поддерживаются.
- Пользователь не может создать диалог с самим собой.
- Начать переписку можно с любым доступным пользователем.
- Наличие подписки для переписки не требуется.
- Между одной парой пользователей существует только один диалог.
- Повторное начало переписки открывает существующий диалог.
- Порядок участников не создаёт второй диалог.
- Пустой диалог не сохраняется до отправки первого сообщения.
- Читать историю диалога могут только его участники.

## Список диалогов

Диалоги возвращаются от недавно активных к более старым.

Для каждого диалога возвращаются:

- собеседник;
- последнее сообщение;
- время последнего сообщения;
- количество непрочитанных сообщений;
- состояние присутствия собеседника.

Если последнее сообщение удалено, система сообщает о его удалении вместо текста.

Также система возвращает общее количество непрочитанных сообщений во всех диалогах.

Пользователь может искать существующие диалоги по имени или псевдониму собеседника.

## Сообщение

Сообщение содержит:

- отправителя;
- получателя;
- текст;
- время отправки;
- время изменения, если сообщение изменялось;
- состояние прочтения;
- признак удаления;
- ссылку на историю, если сообщение является ответом на историю.

В первой версии сообщение содержит текст, включая обычные эмодзи. Ответ на историю дополнительно содержит ссылку на эту историю.

Пустое сообщение отправить нельзя.

Максимальная длина сообщения — 4000 символов.

Фотографии, видео, аудио и другие вложения в первой версии не поддерживаются.

Публикации, занятия и практики как вложения также не поддерживаются.

Ссылка на историю поддерживается только как часть ответа на историю.

## Отправка и получение

- Отправить сообщение может только участник диалога.
- Новое сообщение нельзя отправить заблокированному пользователю.
- Сообщение сохраняется в истории.
- Сообщение передаётся получателю в реальном времени.
- Сообщения имеют однозначный порядок.
- При получении истории сначала возвращаются последние сообщения, затем можно загрузить более старые.
- Повторная обработка одного и того же сообщения не должна создавать дубликат.

## Изменение сообщения

Изменить сообщение может только его отправитель.

После изменения:

- текст не может быть пустым;
- длина текста не превышает 4000 символов;
- время изменения обновляется;
- собеседник получает изменение в реальном времени;
- сообщение не становится непрочитанным повторно;
- новое уведомление не создаётся.

Ограничения по времени на изменение в первой версии нет.

Удалённое сообщение изменить нельзя.

Уже отправленное push-уведомление после изменения сообщения не изменяется.

## Удаление сообщения

Отправитель может удалить своё сообщение для обоих участников.

Другой участник удалить чужое сообщение для всех не может.

После удаления:

- текст сообщения больше не возвращается;
- в истории сохраняется признак удалённого сообщения;
- удаление передаётся собеседнику в реальном времени;
- удалённое непрочитанное сообщение перестаёт учитываться как непрочитанное;
- ранее созданное уведомление остаётся в истории;
- уже отправленный push не отзывается.

Повторное удаление не считается ошибкой.

Удаление сообщения только у себя и удаление всего диалога в первую версию не входят.

Если сообщение заблокировано модератором, его текст становится недоступным, а в диалоге остаётся отметка о недоступном сообщении.

## Прочтение сообщений

Сообщение считается прочитанным только после того, как приложение сообщило системе о его фактическом показе пользователю.

Получение или предварительная загрузка истории не считаются прочтением.

Пользователь может отметить прочитанными все сообщения до выбранного сообщения включительно.

Повторная отметка прочитанным не считается ошибкой.

После прочтения:

- количество непрочитанных сообщений диалога уменьшается;
- общее количество непрочитанных сообщений уменьшается;
- отправитель может увидеть, что сообщение прочитано;
- состояние передаётся отправителю в реальном времени.

В первой версии предусмотрены два состояния:

- отправлено;
- прочитано.

Отдельное состояние доставки не используется.

## Уведомления

Каждое новое сообщение:

- сохраняется как уведомление внутри приложения;
- передаётся для показа всплывающего уведомления;
- отправляется как push-уведомление, если этот вид уведомлений включён;
- передаётся получателю в реальном времени.

Уведомление содержит:

- отправителя;
- начало текста сообщения;
- переход в соответствующий диалог.

Изменение, удаление и прочтение сообщения не создают отдельных уведомлений.

Удаление сообщения не отзывает ранее отправленные уведомления.

## Ограничения первой версии

В первую версию не входят:

- групповые чаты;
- вложения, кроме ссылки в ответе на историю;
- отправка публикаций, занятий и практик;
- ответы на отдельные сообщения;
- реакции на сообщения;
- пересылка сообщений;
- состояние набора текста;
- удаление сообщения только у себя;
- удаление всего диалога;
- аудио- и видеозвонки.

Аудио- и видеозвонки должны быть описаны отдельно.

## Основные сценарии

### Начало переписки

1. Пользователь открывает профиль другого доступного пользователя.
2. Пользователь начинает переписку.
3. Система находит существующий диалог или подготавливает новый.
4. Новый диалог сохраняется после отправки первого сообщения.

### Отправка сообщения

1. Пользователь вводит текст.
2. Система проверяет текст и участников.
3. Система сохраняет сообщение.
4. Сообщение передаётся получателю в реальном времени.
5. Счётчик непрочитанных увеличивается.
6. Получатель получает предусмотренные уведомления.

### Получение истории

1. Пользователь открывает свой диалог.
2. Система проверяет, что пользователь является участником.
3. Система возвращает последние сообщения.
4. Пользователь может последовательно загружать более старые сообщения.

### Изменение сообщения

1. Отправитель изменяет своё сообщение.
2. Система сохраняет новый текст и время изменения.
3. Изменение передаётся собеседнику.
4. Новое уведомление не создаётся.

### Удаление сообщения

1. Отправитель удаляет своё сообщение.
2. Система скрывает текст для обоих участников.
3. Система сохраняет признак удаления.
4. Изменение передаётся собеседнику.
5. Старые уведомления остаются в истории.

### Прочтение сообщений

1. Приложение фактически показывает сообщения пользователю.
2. Приложение сообщает последнее показанное сообщение.
3. Система отмечает его и все предыдущие сообщения прочитанными.
4. Счётчики непрочитанных уменьшаются.
5. Отправитель получает обновление состояния в реальном времени.

## Критерии готовности

- Пользователь может начать личный диалог с другим доступным пользователем.
- Между двумя пользователями не создаётся несколько диалогов.
- Новое сообщение нельзя отправить заблокированному пользователю, но старая история диалога сохраняется.
- История доступна только участникам.
- Пустое сообщение отправить нельзя.
- Длина сообщения не превышает 4000 символов.
- Сообщение сохраняется и передаётся в реальном времени.
- Диалоги упорядочены по последнему сообщению.
- Возвращаются счётчики непрочитанных сообщений.
- Предварительная загрузка не считается прочтением.
- Отправитель видит состояние прочтения.
- Отправитель может изменить своё сообщение.
- Изменение не создаёт новое уведомление.
- Отправитель может удалить сообщение для обоих участников.
- Текст удалённого сообщения не возвращается.
- Новое сообщение создаёт внутреннее, всплывающее и разрешённое push-уведомление.
- Групповые чаты, остальные вложения и звонки не поддерживаются.
- Ответ на историю содержит ссылку на связанную историю.

## Расхождение с текущей реализацией

Личные диалоги, сообщения, счётчики непрочитанных, состояния прочтения и уведомления о новых сообщениях пока не реализованы.

В публичном профиле уже предусмотрено целевое действие начала переписки, но серверного сценария для него пока нет.

Ответ на историю и ссылка на связанную историю пока не реализованы.

Блокировка отдельного сообщения модератором и запрет новых сообщений заблокированному пользователю пока не реализованы.
