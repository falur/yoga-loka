# Сохранённые публикации

## Назначение

Пользователь может сохранять интересные публикации в личный список, чтобы вернуться к ним позже.

## Правила

- Можно сохранить любую доступную опубликованную публикацию, включая свою.
- Черновик, удалённую или заблокированную публикацию сохранить нельзя.
- Повторное сохранение не создаёт дубликат.
- Пользователь может убрать публикацию из сохранённых.
- Повторное удаление из сохранённых не считается ошибкой.
- Список сохранённых публикаций виден только самому пользователю.
- Автор публикации не получает уведомление о сохранении.
- Автор не видит, кто сохранил публикацию.
- Количество сохранений другим пользователям не показывается.
- Сохранение не влияет на лайки, комментарии и репосты.
- Публикации возвращаются от недавно сохранённых к сохранённым раньше.
- Папок и подборок в первой версии нет.

## Недоступные публикации

- Удалённая публикация удаляется из сохранённых.
- Заблокированная публикация временно не возвращается в списке.
- После снятия блокировки она снова появляется в сохранённых.
- Содержимое недоступной публикации не раскрывается.

## Основные сценарии

### Сохранение

1. Пользователь выбирает доступную публикацию.
2. Система добавляет её в личный список.
3. Повторное сохранение не создаёт вторую запись.

### Получение списка

1. Пользователь запрашивает сохранённые публикации.
2. Система возвращает только его личный список.
3. Недоступные публикации в ответ не попадают.

### Удаление из сохранённых

1. Пользователь выбирает сохранённую публикацию.
2. Система удаляет её из личного списка.
3. Сама публикация и её показатели не изменяются.

## Критерии готовности

- Доступную публикацию можно сохранить и убрать из сохранённых.
- Одна публикация не появляется в списке несколько раз.
- Пользователь видит только собственный список.
- Автор публикации не получает уведомление.
- Недоступное содержимое не возвращается.
- Заблокированная публикация возвращается после снятия блокировки.
- Публикации упорядочены по времени сохранения.

## Расхождение с текущей реализацией

Сохранение публикаций и получение личного списка пока не реализованы.
