# Поиск

Поиск позволяет активному пользователю находить пользователей, публикации, занятия, практики и тематические метки.

Карточка описывает только серверные правила поиска. Расположение элементов, переключение разделов и другие особенности экрана здесь не описываются.

## Доступ

- Поиск доступен только вошедшему активному пользователю.
- Не вошедший, заблокированный или удалённый пользователь выполнять поиск не может.
- Аккаунт, ожидающий удаления в течение 30 дней, остаётся активным и может пользоваться поиском.

## Виды поиска

Пользователь передаёт одну поисковую фразу и один выбранный вид:

- пользователи;
- публикации;
- занятия;
- практики;
- тематические метки.

По умолчанию используется поиск пользователей.

Один запрос возвращает результаты только выбранного вида. Смешанная выдача из разных видов не создаётся.

Неизвестный вид поиска отклоняется.

## Данные для поиска

Пользователи ищутся по:

- имени;
- псевдониму;
- духовному имени.

Публикации ищутся по:

- тексту;
- тематическим меткам.

Занятия ищутся по:

- названию;
- описанию;
- тематическим меткам.

Практики ищутся по:

- названию;
- описанию;
- тематическим меткам.

Тематические метки ищутся по своему названию.

Публикации, занятия и практики не ищутся по имени их автора. Автора можно отдельно найти через поиск пользователей.

## Обычный запрос

- Обычная фраза ищется в выбранном виде.
- Поиск выполняется по правилам используемого поискового движка.
- Регистр букв и небольшие опечатки не должны мешать получению подходящих результатов.
- Степень допустимого неточного совпадения определяется настройками поискового движка и может изменяться без изменения бизнес-правил.
- Пробелы в начале и конце фразы не учитываются.
- Пустая фраза или фраза только из пробелов возвращает пустой результат.
- Пустой запрос не возвращает подборки, популярные материалы, историю или рекомендации.

## Поиск по псевдониму

- `@` в начале фразы всегда переключает запрос на поиск пользователей независимо от выбранного вида.
- Поиск выполняется только по псевдониму.
- Имя, духовное имя и другие сведения профиля не участвуют.
- Регистр букв не учитывается.
- Опечатки и близкие варианты не подбираются.
- Результатами являются псевдонимы, начинающиеся с текста после `@`.
- Точное совпадение возвращается раньше остальных.
- Запрос, содержащий только `@`, возвращает пустой результат.

## Поиск по тематической метке

- `#` в начале фразы всегда переключает запрос на поиск тематических меток независимо от выбранного вида.
- Поиск выполняется только по названию метки.
- Регистр букв не учитывается.
- Опечатки и близкие варианты не подбираются.
- Результатами являются метки, начинающиеся с текста после `#`.
- Точное совпадение возвращается раньше остальных.
- Запрос, содержащий только `#`, возвращает пустой результат.

## Доступность результатов

- В поиске находятся только активные и доступные пользователи.
- Заблокированные и окончательно удалённые аккаунты не находятся.
- Аккаунт, ожидающий удаления в течение 30 дней, продолжает находиться.
- Пользователь может найти собственный профиль и свои доступные материалы.
- Из публикаций находятся только доступные опубликованные публикации.
- Черновики, удалённые и заблокированные публикации не находятся.
- Занятия и практики находятся только тогда, когда они доступны ищущему пользователю.
- Метка находится только тогда, когда она используется хотя бы в одном доступном материале.
- Результаты не раскрывают закрытые или служебные сведения.

## Порядок результатов

- Основной порядок определяется поисковым движком по соответствию запросу.
- Точное совпадение возвращается раньше неточного.
- Личная история пользователя и персональные рекомендации на порядок не влияют.
- При одинаковом соответствии более новые публикации, занятия и практики возвращаются раньше.
- При одинаковом соответствии чаще используемые тематические метки возвращаются раньше.
- Подтверждение профиля и количество подписчиков не дают пользователю искусственного преимущества.
- Результаты выбранного вида возвращаются отдельными страницами.
- Отсутствие совпадений возвращает пустую страницу, а не ошибку.

## Обновление поиска

- Новые и изменённые данные могут появляться в поиске с небольшой задержкой.
- Точное время задержки не является бизнес-правилом.
- Перед возвратом сервер повторно проверяет доступность каждого результата.
- Недоступный объект не возвращается, даже если поисковый движок ещё хранит старые сведения.
- После изменения псевдонима пользователь ищется только по текущему псевдониму.
- Устаревшие сведения удаляются из поиска в фоне.

## Основные сценарии

### Обычный поиск

1. Активный пользователь передаёт фразу и выбранный вид.
2. Поисковый движок находит подходящие результаты с учётом регистра, опечаток и соответствия запросу.
3. YogaLoka исключает недоступные результаты.
4. Пользователь получает страницу результатов только выбранного вида.

### Поиск с `@`

1. Пользователь передаёт фразу, начинающуюся с `@`.
2. YogaLoka выполняет поиск только по началу псевдонима.
3. Выбранный ранее вид поиска не учитывается.
4. Пользователь получает доступные профили.

### Поиск с `#`

1. Пользователь передаёт фразу, начинающуюся с `#`.
2. YogaLoka выполняет поиск только по началу названия метки.
3. Выбранный ранее вид поиска не учитывается.
4. Пользователь получает доступные тематические метки.

## Критерии готовности

- По умолчанию выполняется поиск пользователей.
- Один запрос возвращает только один вид результатов.
- Доступны пользователи, публикации, занятия, практики и тематические метки.
- Обычный поиск не зависит от регистра и допускает небольшие опечатки по правилам поискового движка.
- `@` выполняет строгий поиск только по началу псевдонима.
- `#` выполняет строгий поиск только по началу названия метки.
- Пустой запрос ничего не возвращает.
- Недоступные профили и материалы не попадают в результаты.
- Результаты упорядочиваются по соответствию и возвращаются отдельными страницами.
- Персональные рекомендации не используются.
- Устаревшие сведения поискового движка не раскрывают недоступные данные.

## Расхождения с реализацией

Отдельный поиск пользователей, публикаций, занятий, практик и тематических меток пока не реализован.

Нет поискового движка, нет поиска с учётом опечаток, строгих правил для `@` и `#`, общего порядка по соответствию и отдельной постраничной выдачи для каждого вида.
