# Истории

## Назначение

Истории позволяют пользователям публиковать фотографии и видео, которые доступны ограниченное время.

Автор может сохранить истории в публичных подборках своего профиля.

## Участники

- Автор истории.
- Пользователь, просматривающий историю.
- Система YogaLoka.

## Состав истории

История содержит:

- автора;
- одну фотографию или одно видео;
- необязательный текст;
- время публикации;
- время окончания публичного доступа;
- количество просмотров;
- сведения о поставленных лайках.

Пользователь может использовать только собственный медиафайл.

Пустую историю без фотографии или видео создать нельзя.

Несколько медиафайлов создают несколько последовательных историй.

## Публикация и срок действия

- История публикуется сразу.
- Черновики историй в первой версии не поддерживаются.
- История доступна 24 часа с момента публикации.
- После окончания срока история исчезает из публичного списка.
- После публикации изменить историю нельзя.
- Автор может удалить историю до окончания срока.
- Удалённая история сразу становится недоступной.
- Публикация новой истории не создаёт уведомления подписчикам.

## Доступность историй

Активные истории доступны:

- из публичного профиля автора;
- из списка историй для подписок.

Из публичного профиля историю может посмотреть любой пользователь, которому доступен профиль автора.

В основном списке показываются только истории пользователей, на которых оформлена подписка.

Случайные истории других пользователей в этот список не добавляются.

Собственная история пользователя показывается отдельно от историй подписок.

## Порядок историй

В списке подписок:

- сначала показываются пользователи с непросмотренными историями;
- затем пользователи, чьи активные истории просмотрены полностью;
- внутри каждой группы раньше возвращаются пользователи с более новой активной историей.

Истории одного автора показываются от более старых к более новым.

Если автор добавил новую историю, он снова считается имеющим непросмотренную историю для тех пользователей, которые её ещё не видели.

Персональный алгоритм рекомендаций в первой версии не используется.

## Просмотры

История считается просмотренной только после того, как приложение сообщило системе о её фактическом показе.

Получение данных и предварительная загрузка медиафайла не считаются просмотром.

Один пользователь учитывается в просмотрах одной истории только один раз.

Повторный просмотр не увеличивает количество просмотров.

Просмотр автором собственной истории не учитывается.

Количество просмотров и список просмотревших доступны только автору истории.

Другие пользователи не видят количество просмотров и список просмотревших.

Просмотр истории из публичной подборки также учитывается как просмотр этой истории.

## Лайки историй

Пользователь может поставить лайк доступной истории.

- Один пользователь может поставить одной истории только один лайк.
- Повторная установка не создаёт второй лайк.
- Лайк можно снять.
- Повторное снятие не считается ошибкой.
- Автор не может лайкнуть собственную историю.
- Количество лайков и список поставивших лайк доступны только автору.
- Другие пользователи не видят лайки истории.

Лайк истории создаёт:

- сохранённое уведомление внутри приложения;
- push-уведомление, если этот вид уведомлений включён.

Всплывающее уведомление для лайка истории не создаётся.

Снятие лайка не создаёт уведомление и не удаляет старое уведомление.

Просмотр истории уведомление не создаёт.

## Ответ на историю

Пользователь может ответить на доступную чужую историю текстовым сообщением.

Ответ:

- создаёт или открывает личный диалог с автором;
- создаёт сообщение со ссылкой на историю;
- подчиняется правилам длины, изменения, удаления и прочтения сообщений;
- передаётся автору истории в реальном времени;
- создаёт уведомления по правилам чатов.

Ответить на собственную историю нельзя.

Если история истекла или была удалена:

- сообщение остаётся в диалоге;
- текст ответа остаётся;
- содержимое связанной истории больше не возвращается;
- система сообщает, что история недоступна.

Отправка истории третьему пользователю в первой версии не поддерживается.

## Архив историй

После окончания 24 часов история автоматически сохраняется в личном архиве автора.

Архив доступен только автору.

В архиве сохраняются:

- медиафайл и текст истории;
- время публикации;
- просмотры;
- лайки.

Автор может окончательно удалить историю из архива.

Окончательно удалённая история:

- исчезает из архива;
- удаляется из всех публичных подборок;
- становится недоступной по старым ссылкам из сообщений.

История, которую автор удалил до окончания 24 часов, не сохраняется в архиве.

## Подборки историй

Автор может создавать публичные подборки историй в своём профиле.

Подборка содержит:

- название;
- обложку;
- одну или несколько историй;
- порядок показа.

В подборку можно добавить только собственную активную или архивную историю.

Одна история может входить в несколько подборок.

Истории в подборке остаются публичными после окончания 24 часов.

Автор может:

- создать подборку;
- изменить название;
- изменить обложку;
- добавить историю;
- убрать историю;
- изменить порядок историй;
- изменить порядок подборок в профиле;
- удалить подборку.

Удаление подборки не удаляет истории из личного архива.

Удаление истории из подборки не удаляет её из архива или других подборок.

Пустая подборка другим пользователям не показывается.

## Ограничения первой версии

В первую версию не входят:

- изменение опубликованной истории;
- черновики историй;
- несколько медиафайлов в одной истории;
- отправка истории третьему пользователю;
- упоминания пользователей в истории;
- реакции, отличные от одного обычного лайка;
- комментарии под историей;
- уведомления подписчикам о новой истории.

## Основные сценарии

### Публикация истории

1. Пользователь выбирает собственную фотографию или видео.
2. При необходимости добавляет текст.
3. Система проверяет медиафайл.
4. Система публикует историю на 24 часа.
5. История становится доступна в профиле и списке историй подписок.

### Просмотр

1. Пользователь открывает доступную историю.
2. Приложение фактически показывает историю.
3. Приложение сообщает системе о просмотре.
4. Система сохраняет просмотр один раз.
5. Автор видит обновлённое количество и список просмотревших.

### Лайк

1. Пользователь ставит лайк чужой доступной истории.
2. Система сохраняет лайк.
3. Автор видит пользователя в личном списке лайков.
4. Автор получает внутреннее и разрешённое push-уведомление.

### Ответ

1. Пользователь вводит ответ на историю.
2. Система находит или создаёт личный диалог.
3. Система сохраняет сообщение со ссылкой на историю.
4. Автор получает сообщение и предусмотренные уведомления.

### Окончание срока

1. Проходит 24 часа с момента публикации.
2. История исчезает из публичного списка.
3. Система сохраняет историю в личном архиве автора.
4. Если история добавлена в подборку, она остаётся публичной в этой подборке.

### Создание подборки

1. Автор выбирает собственные активные или архивные истории.
2. Автор задаёт название, обложку и порядок.
3. Система создаёт публичную подборку в профиле.

### Удаление истории

1. Автор удаляет активную или архивную историю.
2. Система делает её недоступной.
3. История исчезает из всех подборок.
4. Старые сообщения со ссылкой на неё остаются, но содержимое истории не возвращается.

## Критерии готовности

- История содержит одну фотографию или одно видео.
- История доступна 24 часа.
- Активную историю можно удалить, но нельзя изменить.
- В списке показываются истории текущих подписок.
- Непросмотренные истории возвращаются раньше просмотренных.
- Предварительная загрузка не считается просмотром.
- Один пользователь учитывается в просмотрах один раз.
- Автор видит количество и список просмотревших.
- Лайки истории видны только автору.
- Лайк создаёт внутреннее и разрешённое push-уведомление.
- Ответ на историю создаёт личное сообщение со ссылкой на историю.
- После окончания срока история сохраняется в личном архиве.
- Автор может создавать публичные подборки.
- История в подборке не исчезает через 24 часа.
- Окончательно удалённая история исчезает из подборок и становится недоступна по старым ссылкам.
- Новая история не создаёт уведомления подписчикам.

## Расхождение с текущей реализацией

Истории, просмотры, лайки, ответы, архив и публичные подборки пока не реализованы.

В дизайне предусмотрены просмотр, лайк и ответ на историю, но это пока только демонстрационные данные без серверной поддержки.

Для ответа на историю потребуется дополнить чаты специальной ссылкой на историю. Для лайка истории потребуется зарегистрировать отдельный вид уведомления.
