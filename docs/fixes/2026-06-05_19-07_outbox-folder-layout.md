# Фикс: структура папок outbox-модуля

## Контекст

Пользователь указал, что в модуле `Outbox` непонятная структура: внутри
модуля повторялась папка `Outbox` в `Domain`, `Application`, `Command` и
`Infrastructure`.

Учитывались `docs/rules.md` и `docs/arch.md`. Изменение сделано как перенос
файлов и обновление пространств имён, без изменения поведения классов.

## Что изменено

| # | Файл | Что изменено | Зачем |
|---|------|--------------|-------|
| 1 | `app/src/Modules/Outbox/Domain/*` | Файлы из `Domain/Outbox/*` перенесены в `Domain/*` | Убрать повтор имени модуля внутри доменного слоя |
| 2 | `app/src/Modules/Outbox/Application/Message/*` | Файлы из `Application/Outbox/*` и `Application/Outbox/Message/*` перенесены в `Application/Message/*` | Сделать папку сообщений понятной без повторного `Outbox` |
| 3 | `app/src/Modules/Outbox/Application/Command/*` | Команды из `Application/Command/Outbox/*` перенесены прямо в `Application/Command/*` | Убрать лишний уровень с именем модуля |
| 4 | `app/src/Modules/Outbox/Infrastructure/*` | Инфраструктурные классы из `Infrastructure/Outbox/*` перенесены в `Infrastructure/*` | Убрать повтор имени модуля в инфраструктурном слое |
| 5 | `tests/Unit/Modules/Outbox/*` | Unit-тесты перенесены в папки, соответствующие новой структуре | Сохранить соответствие тестов структуре кода |
| 6 | `app/config/queue.php`, `app/src/**`, `tests/**` | Обновлены `namespace` и `use` | Сохранить автозагрузку и ссылки на классы после переноса |
| 7 | `docs/arch.md` | Обновлено описание структуры `Outbox` | Документация теперь совпадает с кодом |
