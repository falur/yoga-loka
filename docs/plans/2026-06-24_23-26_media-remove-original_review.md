# Strict кросс-CLI ревью плана

Инструмент: `codex exec` (gpt-5.5, reasoning effort high). План:

## Замечания

- [риск] `ProcessMediaHandler` пропускает только статус `Ready`; если старый `MediaUploaded` повторно
  обработается после удаления оригинала, он попытается читать уже удалённый файл и через запись
  ошибки переведёт медиа из `ReadyOriginalRemoved` в `ProcessingFailed` — добавить guard для
  `ReadyOriginalRemoved` в обработку и тест на повторный `ProcessMedia` после удаления оригинала.
- [риск] `recordTemporaryProcessingError()` и `recordPermanentProcessingError()` защищают только
  `Ready`, но не `ReadyOriginalRemoved` — расширить защиту, чтобы сбой старой фоновой обработки не
  портил финальный статус.
- [неясность] план говорит только про Posts, но `FindMediaUrl` также используется в User для
  аватаров; после удаления оригинала аватар станет ссылкой по умолчанию — явно зафиксировать это как
  ожидаемое поведение.
- [тест] не хватает теста на старое сообщение очереди: медиа уже `ReadyOriginalRemoved`, затем
  приходит `ProcessMediaCommand`; ожидаемо не должно быть чтения S3, смены статуса и записи ошибки.
- [тест] план требует 100% покрытия, но проверка указана через `make test`, а покрытие проверяет
  отдельная цель `make test-coverage` или `make qa` — заменить финальную проверку на `make qa`.
- [нарушение] русский текст локали «у медиа нет ни одной конверсии» выбивается из стиля переводов,
  где используется «преобразование» — заменить на «у медиа нет ни одного преобразования».
- [тест] для новых ошибок важно проверять ключи `app.media.original_removed`,
  `app.media.original_not_removable`, `app.media.no_conversions_to_keep`, а не только класс
  исключения — добавить проверки `getMessage()`.
- [риск] guard «есть хотя бы одна конверсия» считает любую строку конверсии, хотя у конверсий есть
  статусы `Processing`/`Ready`/`ProcessingFailed` — либо ограничить guard статусом `Ready`, либо
  зафиксировать, что сейчас в БД создаются только готовые конверсии.
- [неясность] план ссылается на старый research-файл, хотя в шапке указано, что связанного research
  нет — пометить как исторический контекст.
